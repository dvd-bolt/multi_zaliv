## Что исправлено

- Новое видео сразу становится выбранным. Запоздавший ответ опроса сервера больше не возвращает старый список.
- Нажатие текущего исходника сохраняет редактируемые настройки; повторный клик сохранения выполняет одну операцию.
- Ошибка видна внутри открытого диалога, а не за его затемнением. При восстановлении сервера сообщение об отсутствии связи исчезает.
- Подтверждённая отмена выигрывает у ещё не начавшейся отправки. Повтор запрещён для задания с известным внешним ID; результат «неизвестен» не отправляется заново автоматически.
- Проверка обработки YouTube больше не сдвигает отсчёт интервала до следующей отправки. Чтение метрик не удерживает запись SQLite между сетевыми запросами.
- Запись канала с заданиями нельзя перепривязать к другому каналу. Отмена подключения делает поздний OAuth callback недействительным. Это проверено с тестовым API, без настоящего входа.
- Повреждённый PNG даёт понятную ошибку и не оставляет лишний файл. Длинный текст помещается в баннер целиком, с переносами. Его предпросмотр использует тот же PNG, что и экспорт.
- Ненулевое начало времени MKV не добавляет лишние секунды. Сбой создания встроенного баннера переводит задание в ошибку, освобождая очередь.
- Доступны «До / после», скрытие баннера, просмотр готового MP4 и удаление исходника из списка монтажной. Удаление из списка сохраняет оригинал и существующие задания.
- Длинные имена и страницы 30 записей аккаунтов укладываются в рабочую область 1024×600. Баннер у края предпросмотра остаётся внутри кадра.

## Проверки

- [x] **Сборка:** TypeScript/Vite и ruff проходят.
- [x] **Автоматические проверки:** 25 тестов пройдены. У тестового клиента есть одно предупреждение о будущем переходе httpx → httpx2; приложение не падает.
- [x] **Браузер:** 22 основных состояния плюс расширенный сценарий длинных имён, страниц, ошибок, быстрых кликов, импорта и восстановления связи.
- [x] **Консоль/сеть:** необработанных JavaScript-исключений и неожиданных сетевых ошибок в расширенном прогоне нет. Ответы 400/503 намеренно вызваны для проверки ошибок ввода и потери связи.
- [x] **Фоновые процессы:** работа после закрытия вкладки, прерывание рендера и восстановление, сохранность данных после перезапуска API, запрет второго worker, быстрый Start → Stop → Start.
- [x] **Файлы:** 3 синтетических исходника дали 18 корректных вариантов; дополнительно проверен 30-секундный ролик с движением/звуковыми импульсами и полный существующий ролик из «Банерки».
- [x] **Хранение:** миграция старой базы сохраняет записи; удаление из списка сохраняет исходник; секреты защищены DPAPI, а тестовые данные изолированы от рабочей базы.

## Граница готовности

Локальная обработка и перечисленные сценарии проверены. Реальные Google OAuth, публикации/видимость/метрики YouTube и TikTok ещё требуют подключения и согласованного теста. Историческая аналитика, сравнение вариантов за одинаковое время после публикации, выбор папки данных в UI и полный день остаются в дорожной карте. Gemini не включён. Внешних публикаций в ходе проверки не было; рабочая база без тестовых аккаунтов и метрик, очередь на паузе.
