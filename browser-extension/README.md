# SurvivalFlow — подключение TikTok из обычного Chrome

Расширение работает только после вашего нажатия. Читает собственный @профиль и сессию TikTok в текущем профиле Chrome, передаёт их только локальной программе после проверки одноразового кода. Не имеет доступа к Google, паролям или другим сайтам. Не публикует видео. Не сохраняет сессии и код в файлы или chrome.storage.

## Установка один раз

1. В своём обычном Chrome откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку `browser-extension`.
4. При желании закрепите SurvivalFlow через кнопку расширений Chrome.

## Подключение аккаунта

1. В SurvivalFlow откройте «Каналы → Подключение → Открыть TikTok в моём Chrome».
2. Скопируйте показанный код подключения. Он действует 10 минут.
3. В обычном Chrome войдите в TikTok и откройте свой «Профиль».
4. Нажмите расширение SurvivalFlow, вставьте код и нажмите «Подключить этот TikTok».
5. Вернитесь в программу и подтвердите найденный @аккаунт. Без подтверждения сессия не сохраняется в DPAPI.

Код используется однократно. Для другого аккаунта используйте нужный профиль Chrome либо переключите аккаунт на сайте и создайте новый код в программе. Для нестандартного порта раскройте «Адрес локальной программы». Автопубликация TikTok требует отдельной проверки и не включается от одного лишь входа.
