# Как подготовить ролик и опубликовать его

**Основной режим обновлён 26 октября:** «В очередь» → время → «Запустить автозалив». Рендер и отправка теперь без второго подтверждения; флажок включён по умолчанию. Для ручного просмотра MP4 его можно выключить. Подробно: [Автозалив](AUTOPUBLISH_GUIDE.md). Ниже сохранена инструкция отдельных операций и ручного режима.


Обновлено: 26 октября 2026 года.

## Баннер со стоп-кадром

1. Открой SurvivalFlow через ярлык. После обновления закрой окно и открой снова.
2. В «Монтажной» нажми «+ Видео» и выбери исходник.
3. Справа во вкладке «Баннер» загрузи свой файл баннера. Можно оставить встроенный текстовый.
4. Выбери середину либо ручной таймкод, задай длительность, размер и положение.
5. На основной вкладке «Баннер» включи «Стоп-кадр» и «Звук баннера». При выборе нового баннера первая галочка включается автоматически, вторая — если файл содержит звук.
6. Проверь через «К баннеру» и кнопку воспроизведения.

Например: 60 секунд исходника, баннер на отметке 30 секунд длительностью 3 секунды. Получится 63 секунды: первые 30 секунд → стоп-кадр и баннер со звуком рекламы → оставшиеся 30 секунд мультфильма. Если «Звук баннера» выключен или дорожки нет, во время стоп-кадра будет тишина. Старые задания сохраняют свои настройки. Горизонтальная позиция находится в дополнительных параметрах.

## Создать готовый MP4

1. Во вкладке «Фильтры» задай нужные изменения.
2. Во вкладке «Выпуск» укажи название/описание и выбери нужные аккаунты в назначениях. Видимость по умолчанию «Только я»; для открытой публикации нужно выбрать открытый доступ.
3. Нажми «В очередь · N вариантов» и подтверди состав пакета.
4. Если сверху видна кнопка «Запустить», нажми её: это запускает обработку очереди.
5. Перейди в раздел очереди. Дождись статуса «Готов к проверке».
6. Открой задание → «Посмотреть MP4» либо «Скачать и проверить MP4».

Изменения настроек после создания задания не меняют уже созданный вариант. Для другого результата создай новый вариант.

## Публикация

TikTok подключён: пользователь подтвердил подключение, API показывает connected / browser_login. Автоматическая отправка пока не проверена; ограничение browser_verified сохраняется. Поэтому сейчас рабочий путь — скачать готовый MP4, открыть TikTok в обычном Chrome, воспользоваться загрузкой видео, выбрать файл, проверить аккаунт/описание/видимость и опубликовать самостоятельно. Нажатие «В очередь» само по себе ничего на TikTok не публикует.

В программе предусмотрено: задание → «Подтвердить отправку» → проверка файла, аккаунта и видимости → подтверждение. Для TikTok текущий вход этого шага автозалива ещё не открывает. Проверенный автозалив, внешний ID и статистика остаются задачей следующего этапа. Для реального теста заранее согласуются файл, аккаунт и видимость.

YouTube подключается отдельно через Google OAuth. Код отправки через API существует, но реальная загрузка на пользовательский канал ещё не подтверждена.
