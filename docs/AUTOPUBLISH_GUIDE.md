# Автозалив: рендер и отправка без лишних кнопок

Один раз настрой баннер, подключи каналы и выбери видимость. Новое видео перенесёт эти настройки из последнего активного исходника. Название/описание и подтверждения содержания не копируются.

## Для каждого видео

1. Загрузи исходник. При включённом Gemini дождись описания или внеси свой текст.
2. Нажми «В очередь · N вариантов».
3. Укажи время отправки. Пустое поле означает отправку сразу после рендера.
4. Оставь включённым «Автозалив после рендера». В диалоге видны каналы, материал и видимость. Если нужны подтверждения БУБА — одна общая галочка с перечисленными условиями, её нужно отметить самостоятельно.
5. Нажми «Запустить автозалив». Дальше ничего разрешать не требуется.

Программа сама запускает очередь, создаёт MP4 и отправляет его в нужное время. Статусы: «В очереди» → «Рендер» → «Запланирован» → «Отправляется» → «Обработка платформой». Последняя обработка/модерация зависит от платформы. Следующие ролики одного канала учитывают интервал из настроек.

Для доступного всем ролика нужна видимость «Открытый доступ». Если сохранено «Только я», программа не меняет это сама.

Окно программы можно закрыть, worker продолжит работу. Компьютер должен быть включён. Пропущенное из-за сна/выключения больше 10 минут время нужно выбрать заново. Если рендер немного опоздал при работающей программе, отправка продолжится после готовности.

## Что ещё может потребовать действия

- Истёкший вход/CAPTCHA или первый непроверенный TikTok-аккаунт: восстановить доступ/пройти проверочную отправку.
- Неподходящий баннер: исправить геометрию, длительность, звук или формат. Подтверждение содержания не обходит эти проверки.
- «Результат неизвестен»: проверить фактическую публикацию; автоматически второй раз программа не отправляет.
- Для подготовки без отправки выключи «Автозалив после рендера» и нажми «Создать MP4».

Старые задания не получили автозалив автоматически. Для ещё не отправленного задания можно повторно выбрать тот же исходник/каналы в монтажной и явно запустить автозалив: при неизменном варианте используется существующая задача. Опубликованные/неопределённые/отменённые задачи не перезапускаются этим путём.

Для обновлённого интерфейса один раз закрой и открой SurvivalFlow.
