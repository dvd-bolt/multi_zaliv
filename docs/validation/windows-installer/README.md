## Состав и поведение

Включены CPython 3.13.2 x64 с изолированным `python313._pth`, Python-зависимости, Playwright с собственным Node-драйвером, рабочий React/Vite-интерфейс, FFmpeg/ffprobe, модель faster-whisper base, иконка и расширение Chrome. Глобальные Python и Node.js не требуются. Native `FrameFlow.exe` запускает вложенный Python; API и worker живут независимо от окна. Нативные библиотеки и локальная модель действительно загружены из установленной папки.

Пользовательская установка в `%LOCALAPPDATA%\Programs\FrameFlow`, без администратора; база/медиа/логи/секреты отдельно в `%LOCALAPPDATA%\FrameFlow\data`. `SURVIVALFLOW_DATA` по-прежнему поддерживается, запуск из исходников сохраняет прежнюю папку `data`. В установщик не входят рабочая SQLite, исходные видео, сессии, cookies или ключи. Проверка содержимого и контрольные суммы выполняются до упаковки. Лицензии Python и зависимостей, сведения FFmpeg и MIT-лицензия модели сохранены в комплекте.

Нужны Windows 10 2004+ или Windows 11 x64, .NET Framework из Windows и WebView2. При отсутствии WebView2 включён официальный подписанный загрузчик Microsoft (требуется интернет). Для интерактивного TikTok остаётся нужен установленный Chrome. Аккаунты/API подключает владелец; установщик не переносит данные разработки и не включает автопубликацию старых материалов. После установки новый профиль данных пустой и очередь на паузе.

Перед обновлением установленной версии нужно завершить операции и полностью остановить FrameFlow. Установщик не закрывает процессы принудительно. Удаление программы не удаляет внешнюю папку данных. В меню Пуск создаются запуск и полная остановка; значок на рабочем столе — необязательный. Установщик приложения не подписан сертификатом издателя.

## Воспроизведение

После установки исходных зависимостей через `scripts/setup.ps1` и модели через `scripts/download_story_model.py`, при наличии Inno Setup 7:

```powershell
.\.venv\Scripts\python.exe scripts/build_windows.py --iscc "C:\путь\к\Inno Setup 7\ISCC.exe"
.\.venv\Scripts\python.exe scripts/verify_installer.py releases/FrameFlow-Setup-0.2.0-x64.exe
```

Упаковка использует явный список исходников/ресурсов, не копирует `data` целиком, исключает machine-specific `.pth` и `direct_url.json`, проверяет автономный runtime перед компиляцией установщика. Скрипт проверки использует отдельный AppId и не ставит продукт поверх рабочего экземпляра. Скачанные инструменты сборки находятся только в игнорируемой `data/tools/build`; цифровые подписи загрузчиков проверены: Inno Setup — Pyrsys B.V., WebView2 — Microsoft Corporation.

Источники: [Python — изоляция и поставка приложения](https://docs.python.org/3.13/using/windows.html), [Inno Setup](https://jrsoftware.org/isinfo.php), [Microsoft — обнаружение и установка WebView2](https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution).
