# «Выпуск» — проверка реализации, 10.11.2026

План: `docs/proposals/2026-11-10-publication-flow.md` (утверждён пользователем 10.11.2026). Дизайн: `DESIGN_SPEC.md` v1.19, раздел 21.

## Где проверено

Linux-сервер, отдельная временная база на каждый прогон: синтетические ролики (ffmpeg testsrc), фиктивные аккаунты, локальная заглушка проверки входа. Ни одного запроса к TikTok/YouTube/Google; настоящих публикаций не было. Windows-окно WebView2 и настоящий worker (`msvcrt`) здесь не запускались.

## Не проверено

- Настоящая первая публикация TikTok через «Выпуск» и обновление программы на Windows-ноутбуке.
- Миграция схемы 12 на копии рабочей базы: базы на сервере нет. Миграция только создаёт новую таблицу; тест миграции старой схемы проходит.
- `scripts/verify_stories_ui.cjs` использует файл голоса с ноутбука и на сервере не запускается; в Историях добавлена только кнопка «К публикации».
- `verify_autopublish_ui.cjs`, `verify_edges.cjs`, `verify_ui.cjs`, `verify_growth_ui.py` проверяют удалённый диалог «Рендер и публикация» и требуют переписывания под «Выпуск».
