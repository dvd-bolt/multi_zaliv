# Precision Mono — перенос в рабочий FrameFlow

Проверено 6 ноября 2026 года. Это проверка рабочего React-интерфейса и локальных сценариев, а не демонстрационного HTML-макета.

## Результат

Precision Mono перенесён в существующий frontend без замены API, очереди, аккаунтов или формата данных. Нейтральные поверхности и светлый акцент распространяются на монтажную, очередь, каналы, статистику, настройки и диалоги. Сохранены рабочие функции, включая БУБА, стоп-кадр, звук, фильтры, расписание, авторский комментарий и проверки входа.

Изменены библиотека исходников (компактные строки с настоящими миниатюрами), логотип, геометрия панелей, вкладки инспектора, предпросмотр и таймлайн. Вкладки управляются стрелками/Home/End, после закрытия диалога фокус возвращается к вызвавшему действию. Учитывается reduced motion. Исходные видео и баннеры сохраняют свои цвета и содержимое.

При проверке Gemini устранён ранее существовавший дефект: автоматические жанровые хэштеги больше не мешают запуску анализа нового ролика с пустыми названием и содержательным описанием. При этом список автоматически добавленных тегов используется только для распознавания пустого описания, не навязывается новому тексту Gemini. Ручной текст не затирается.

## Рабочий запуск

Перед запуском создана согласованная SQLite-копия `data/backups/before-precision-mono-20261106-220543.sqlite3`, quick_check=ok. Контрольные количества: 33 задания (published=28, cancelled=4, waiting_auth=1), 24 записи материалов. В интерфейсе видны 23 неархивных материала; число записей базы и число видимых материалов — разные показатели.

Рабочий FrameFlow запущен через штатный `scripts/launch.py`: окно Windows найдено, API PID 5380, worker=true, frontend build `b5edd269420045f8`. HTML API совпадает с текущим frontend/dist/index.html. Очередь, её состояния и число сохранённых материалов после запуска не изменились. Доказательства: `before-launch.json`, `launch-results.json`.

Новые реальные материалы не публиковались; результаты TikTok/YouTube не подменяются имитациями. Полная приёмка настоящего пакета FF-A1 остаётся отдельной задачей. Замороженный эталон `docs/design/assets/design-v1/` не переписывался.
