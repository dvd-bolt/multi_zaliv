# Исправление Windows-блокировки состояния нарезок — 10.11.2026

Пользователь сообщил об ошибке загрузки YouTube: `WinError 5` при замене `state.tmp` → `state.json`. Ошибка подтверждена локально: открытый читателем JSON действительно запрещает `os.replace` на этой Windows. API и worker работают в разных процессах; их `threading.RLock` не защищает замену от чтения другим процессом. Предыдущая синтетическая проверка загрузку по внешней ссылке не охватывала.

## Исправление

- `backend/clips.py`: отдельный временный файл для каждого сохранения; атомарная замена с максимум 10 попытками при `PermissionError` и короткой задержкой. При постоянном отказе старая JSON-запись сохраняется, временный файл убирается, ошибка не скрывается.
- Прогресс скачивания сохраняется не чаще четырёх раз в секунду вместо записи на каждый пакет. Отмена и итоговое сохранение остаются.
- Для источника с исходной ссылкой без готового файла доступна кнопка «Повторить загрузку». Используется тот же ID/каталог и частичные файлы yt-dlp; обработка активного источника повторно не запускается. Для готового видео сохранено «Найти заново».
- Precision Mono и геометрия не менялись. Ошибка не требует запуска от администратора или изменения прав Windows.

## Проверки

- 8 целевых тестов: `tests/test_clips_storage.py` и `tests/test_clips.py`, все успешны (`pytest.txt`, `tests.xml`). Новый Windows-тест удерживает реальный открытый файл, затем отпускает его: сохранение завершается корректно. Проверены постоянная блокировка/целостность/очистка, повтор того же источника с сохранением `.part`, защита от двойного запуска, отсутствие повтора для утраченного локального файла без ссылки; прежние анализ/MP4/монтажная проходят.
- 5 сценарных UI-проверок, 1024×600 и 1440×900 без переполнений: настоящий технический MP4 и воспроизведение, пагинация, сохранение, перенос без публикаций, новая кнопка повтора для упавшей ссылки (`ui/ui-results.json`). Расшифровка в UI-тесте синтетическая, запросов к внешним сервисам нет.
- TypeScript/Vite build, Ruff, `git diff --check`, детектор Impeccable (`[]`) успешны.
- Полный набор 267 тестов прошёл до этого исправления в отчёте `../growth-tools-update-2026-11-10/`; после исправления выполнены целевые проверки выше, повторный полный прогон не заявляется.
