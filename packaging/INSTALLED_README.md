# FrameFlow 0.2.0 для Windows x64

Запуск: ярлык FrameFlow. Полная остановка API и worker: «Остановить FrameFlow полностью» в меню Пуск. Закрытие окна оставляет обработку в фоне.

Python, библиотеки, FFmpeg/ffprobe и модель локальных субтитров включены. Python и Node.js отдельно устанавливать не нужно. Для окна нужен Microsoft Edge WebView2; если его нет, установщик запускает официальный загрузчик Microsoft, которому требуется интернет. Для интерактивного TikTok-входа нужен установленный Google Chrome. Аккаунты и API подключаются владельцем отдельно.

Данные хранятся в `%LOCALAPPDATA%\FrameFlow\data`, отдельно от установленных файлов. Обновление/удаление программы их не удаляет. Сборка не содержит чужих или разработческих аккаунтов, исходных видео, cookies, токенов и API-ключей. DPAPI-секреты принадлежат текущему пользователю Windows. Перед обновлением завершите операции и остановите FrameFlow полностью; не прерывайте отправку на платформу.

Существующая рабочая папка проекта `multi_zaliv` не переносится автоматически. Если вы пользовались версией из исходников, она и её данные остаются на прежнем месте. Одновременный запуск двух экземпляров с разными папками данных на порту 8765 блокируется. Перенос существующих данных выполняется отдельно, с копией базы и сохранением исходных файлов/путей.

Первая версия установщика не подписана сертификатом издателя. Проверяйте контрольную сумму из сопроводительного файла. Лицензии Python-пакетов сохранены в runtime/Lib/site-packages, лицензия Python — runtime/LICENSE.txt, сведения FFmpeg — resources/tools, остальные уведомления — ThirdPartyNotices.
